# Remote Control Plane

## About
This is my DIY RC airplane project. I built it using a brushless motor, FlySky radio system, and a LiPo battery. The goal was to make a simple plane that can actually fly while learning how RC electronics and aerodynamics work.

## BOM (Bill of Materials)
- 2200KV Brushless Motor - $7.26  - https://s.daraz.com.np/s.ZRkRP
- 30A ESC - $6.47 - https://s.daraz.com.np/s.ZRkRL
- 2200mAh LiPo Battery - $13.88 - https://s.daraz.com.np/s.ZRkPR
- FlySky Transmitter + Receiver - $66.99 - https://s.daraz.com.np/s.ZRk8n
- 2 Servo Motors - $5.42 - https://s.daraz.com.np/s.ZRk9u
- Propeller - $1.30 - https://s.daraz.com.np/s.ZRkRG
- Foam board (for the airplane body)
- Control horns, push rods, glue, and other small parts

## Wiring
- CH1 → Aileron Servo
- CH2 → Elevator Servo
- CH3 → ESC (Throttle)

The ESC is connected to the brushless motor and battery, and it also powers the receiver through its BEC.

## What I Learned
- How to connect RC electronics correctly.
- How an ESC controls a brushless motor.
- Why the center of gravity (CG) is important.
- How control surfaces affect the airplane during flight.
- Basic troubleshooting when something doesn't work.

## Challenges
This project wasn't easy. I had to reconnect wires a few times, figure out the correct receiver channels, and make sure everything was balanced before flying. There were a lot of small mistakes, but fixing them helped me learn.

## Future Improvements
- Add landing gear.
- Make the plane lighter.
- Improve the body design.
